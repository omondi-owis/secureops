# SecureOps — API Reference

Interactive docs are auto-generated by FastAPI at **`/docs`** (Swagger UI) and **`/redoc`** (ReDoc) on any running instance. Authentication uses `OAuth2PasswordBearer` — click **Authorize** in Swagger and enter admin credentials, or pass `Authorization: Bearer <token>`.

All endpoints live under **`/api`**. Tags: `Authentication`, `Dashboard`, `Hosts`, `Scanning`, `Logs`, `Security Events`, `Wazuh`, `Incidents`, `Vulnerabilities`, `Reports`, `Audit`, `Settings`, `System`.

## Authentication

| Method | Path | Role | Description |
|---|---|---|---|
| POST | `/api/auth/login` | — | Form login (`username`,`password`) → `{access_token, user}` |
| POST | `/api/auth/token` | — | OAuth2 password grant (same payload) |
| POST | `/api/auth/logout` | any | Ends session + audit record |
| GET | `/api/auth/me` | any | Current user profile |
| POST | `/api/auth/change-password` | any | Change own password |

## Error format

```json
{ "detail": "human-readable, safe message" }
```

Status codes: `401` unauthenticated, `403` forbidden, `404` missing, `409`/`400` validation, `422` schema error, `423` account locked, `429` rate limited, `503` upstream unavailable (Wazuh/Nmap), `500` internal (logged server-side, generic client message).
